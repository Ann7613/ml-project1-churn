# ml-project1-churn

# Churn Prediction Models


## Ejercicio — Predicción de Churn (Telecom)
- `preprocessing.py` — limpieza y preprocesamiento de datos
- `models.py` — Regresión Logística y Random Forest con GridSearchCV
- `evaluation.py` — métricas y matrices de confusión
- `threshold.py` — optimización del umbral de decisión
- `model_analysis.md` — análisis y comparación de modelos

## Ejercicio A — Precio de Vivienda
- `Caso_casas_GD.py` — Regresión Lineal Múltiple con Gradient Descent y Ecuación Normal
- `Caso_casas_LR.py` — Regresión Logística Binaria (clasificación PREMIUM/ESTÁNDAR)
